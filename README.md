# Simply Gravel for Py

Place Pyanodon's **gravel** on the ground as a gravel floor tile.

This is a Pyanodon's version of [Simply Gravel](https://mods.factorio.com/mod/simply-gravel) by chesapeake. Py gives you plenty of gravel, so this mod lets you use it as flooring. Unlike Simply Gravel, base **stone** is left alone and is not placeable.

### Features
- Place gravel straight from your inventory, like stone path. Mine it to get the gravel back.
- 10% walking speed bonus on gravel.
- No new items, recipes or technology. Just the tile.
- Stone path and concrete draw cleanly on top of gravel.

### Compatibility
- **Requires** Pyanodon's Coal Processing.
- **Replaces Simply Gravel.** The two can't be enabled together. Existing Simply Gravel tiles in a save are converted to this mod's gravel automatically; converted tiles give gravel instead of stone when mined.
- **[Cleaned Concrete](https://mods.factorio.com/mod/CleanedConcrete):** placing gravel clears decoratives underneath. This applies only to newly placed gravel.
